## Project Description
This is a simple interactive web application that allows users to enter their name and age, stores the data using localStorage, and displays personalized content. The system also calculates the user's age in months and shows different messages based on whether the user is an adult or not.

The project is built using HTML, Tailwind CSS, and JavaScript.

## Features
- User input form for name and age
- Data storage using localStorage
- Personalized greeting message
- Age calculation in months
- Conditional messages based on age
- Motivational quotes displayed using a loop
- Dark mode toggle system
- Navigation between dashboard and quotes page

## How to Use the System

1. Open the project using `index.html`.
2. Enter your name and age in the form provided.
3. Click "Save Data & Continue".
4. You will be redirected to the quotes page.
5. The system will display:
   - Personalized greeting
   - Age in months
   - Age-based message
   - Motivational quotes
6. Click "Back to Dashboard" to return to the main page.
7. Toggle dark mode using the theme button.
